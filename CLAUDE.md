# Cloud Resume — Guía de actualización

Este repo es mi AWS Cloud Resume Challenge (index.html + style.css + script.js).

## Cuando termino un proyecto de portfolio nuevo, actualizame index.html así:
- Agregar una tarjeta nueva en <section><h2>Projects</h2> siguiendo EXACTAMENTE
  el patrón de las tarjetas existentes: div.project.highlight con border-left
  de un color no usado todavía, <h3> con ese mismo color, lista de bullets
  técnicos, párrafo "Technical Challenge" si aplica, y link a GitHub.
- Colores ya usados: naranja #f97316, verde #16a34a, celeste #0ea5e9,
  rojo #dc2626, índigo #4f46e5, teal #0d9488. Usar uno nuevo para el próximo.
- Tono: profesional, en inglés, enfocado en decisiones de arquitectura y
  seguridad (soy Cloud & AI Engineer con especialización en Security).
- Ubicar la tarjeta nueva en orden cronológico dentro de la sección.
